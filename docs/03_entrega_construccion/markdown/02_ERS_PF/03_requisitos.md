# **3\. Requisitos específicos**

## **3.1 Interfaces externas**

**Interfaces de usuario**

***Sistema 1 (Administrador)***

***V***entana principal con pestañas:

* **Productos**: botones Nuevo, Editar y Actualizar, y diálogo con nombre, descripción y precio.  
* **Mercancía:** botones Registrar, Actualizar y Ver QR.  
* **Ventas:** botones Registrar venta y Actualizar.  
* **Historial de ventas:** botones Actualizar y Abrir QR.

Las operaciones se ejecutan en segundo plano para no congelar la interfaz y los errores de validación se marcan por campo.

***Sistema 2 (Proveedor)***

*V*entana de registro de venta con la tabla de mercancía disponible (con filtro de texto), selección de tienda y usuario, botón para registrar la venta y vista previa del QR (doble clic sobre una unidad).

Los códigos de error se traducen a mensajes comprensibles.

**Interfaces de comunicación**

* Sockets TCP, una conexión por solicitud y un objeto JSON por línea en UTF-8.  
* Solicitud: idSolicitud, nombreServicio, nombreOperacion, parametros y fechaHora.  
* Respuesta: idSolicitud, estado (EXITO o ERROR), resultado, código y mensaje de error (si aplica) y fechaHora.  
* Puertos por defecto: Broker 5000, Sistema 1 6000, MariaDB 3306 (configurables con variables de entorno).

## **3.4 Restricciones de diseño**

* **RNF-09 Patrón Broker:** el cliente y el proveedor deberán comunicarse solo a través del Broker, sin conocerse ni instanciarse directamente.  
* **RNF-10 Organización del Broker:** el Broker deberá organizarse en los paquetes network, registry, routing y util, y no deberá contener lógica de negocio ni acceder a la base de datos.  
* **RNF-11 Contrato común:** los tres componentes deberán compartir el contrato de mensajes definido en el módulo common (Solicitud, Respuesta, CodigoError, Servicios, Operaciones, GsonFactory).  
* **RNF-12 MVC:** el Sistema 1 y el Sistema 2 deberán organizarse en capas Modelo-Servicio-Repositorio y ejecutar las llamadas de red con SwingWorker, fuera del hilo de la interfaz.  
* **RNF-13 Configuración:** toda la configuración (puertos, hosts, tiempos límite, reintentos y pools) deberá definirse con variables de entorno.  
* **RNF-14 Base de datos:** el Sistema 1 deberá almacenar sus datos en MariaDB con el esquema definido (roles, usuarios, productos, historial\_precio, mercancia, tiendas\_almacenes, ventas).
